# Changelog

All notable changes to Endpoint Lab will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of Endpoint Lab
- Domain and collection management
- API path organization with HTTP method support
- Header and body preset management
- JSON import functionality for paths, headers, and bodies
- Request execution with collection-based base URLs
- Auto-update functionality for seamless updates
- Cross-platform support (Windows, macOS, Linux)

### Changed
- Menu icons now display on separate lines and align to the left
- Action buttons moved to dropdown menus for cleaner UI

### Fixed
- None

## [0.1.0] - 2026-11-24

### Added
- Initial public release
- Core HTTP client functionality
- Rust-based backend for performance
- React-based frontend for modern UI
- Persistent local storage
- Workspace-based data management
